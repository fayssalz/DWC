## Diamond Weight & Parcel Price Calculator

This professional-grade calculator allows users to estimate the carat weight of diamonds based on their physical dimensions and calculate total parcel pricing. It is designed for technicians and jewelers who require precision in both metallurgical calculations and diamond synthesis assessment.

---

### 💎 Key Features

* **Dimensional Weight Estimation:** Accurate weight calculations for various diamond shapes (Round, Oval, Emerald, etc.) using standardized gemstone formulas.
* **Visual SVG Feedback:** A dynamic SVG display that scales in real-time based on your input dimensions.
* **Physical Screen Calibration:** Includes a calibration tool to ensure the digital representation matches the physical stone size on your specific hardware, whether using a **Windows 11** laptop or a **Samsung** mobile device.
* **Parcel Pricing:** Calculate total stone counts, aggregate carat weight, and final market value within a single interface.
* **Unlocked Pricing Mode:** A toggle-based system to switch between basic weight estimation and full price-per-carat analysis.

---

### 🛠 Technical Implementation

The project is built with a focus on high-performance integration and local utility:

* **Frameworks:** jQuery for DOM manipulation and vanilla JavaScript for metallurgical math.
* **Graphics:** Real-time SVG rendering for shape visualization.
* **Optimization:** Light footprint, suitable for integration into local AI environments or mobile UI wrappers like **One UI**.

---

### 📐 Weight Formulas Used

The calculator utilizes the standard density of diamond ($3.52$ $g/cm^3$) to derive carat weight.

**Example (Round Brilliant):**


$$\text{Weight (ct)} = \text{Diameter}^2 \times \text{Depth} \times 0.0061 \times \text{Girdle Correction}$$
